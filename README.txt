Serve Legal Audit Notify — personal-use prototype

This version uses the exact logo image supplied by the user and a navy background matching it. Status preview options include Audit submitted, Audit approved, Approving query, Query raised, In progress, Rejected, Payment pending, Paid, and Other status.

Limitations:
- It does not log into or check the Serve Legal portal.
- Notifications are local previews only, not real remote push notifications.
- Live monitoring needs a permitted status source and a remote push service.
- Never place Serve Legal passwords, session cookies, or private audit details in this public repository.
- Independent personal prototype; not affiliated with or endorsed by Serve Legal.
